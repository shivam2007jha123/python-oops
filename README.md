# Python OOP Concepts and Practice

## 📌 About the Project

This repository contains Python practical assignments focused on Object-Oriented Programming (OOP). It demonstrates the fundamental concepts of OOP through simple programs and real-world examples.

The purpose of this project is to understand how classes and objects work and how inheritance, polymorphism, encapsulation, and abstraction can be implemented in Python.

## 🎯 Topics Covered

* Classes and Objects
* Constructors (`__init__`)
* Inheritance
* Polymorphism
* Encapsulation
* Abstraction

## 📝 Practical Tasks

### Task 1: Classes and Objects — 20 Marks

* Create a class representing a real-world entity.
* Define appropriate attributes and methods.
* Create at least two objects.
* Display the information of each object.

### Task 2: Constructors — 15 Marks

* Initialize object attributes using the `__init__` constructor.
* Create objects with different attribute values.
* Access initialized attributes.
* Display object information using a method.

### Task 3: Inheritance — 20 Marks

* Create a parent class and a child class.
* Define common attributes and methods in the parent class.
* Add specific functionality to the child class.
* Demonstrate inherited functionality using objects.

### Task 4: Polymorphism — 15 Marks

* Create two different classes with a method having the same name.
* Implement different behaviors in each class.
* Demonstrate polymorphism through method calls.

### Task 5: Encapsulation and Abstraction — 30 Marks

**Encapsulation**

* Use private or protected attributes.
* Implement methods to access or modify data.
* Demonstrate controlled access to object attributes.

**Abstraction**

* Create an abstract class using Python's `abc` module.
* Define an abstract method.
* Implement the abstract method in a child class.
* Demonstrate the implementation using objects.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Concepts:** Object-Oriented Programming (OOP)
* **Module:** `abc` for abstraction
